# Windows setup illustrations

`CodexSetup.gif` and `ClaudeSetup.gif` are synthetic Windows PowerShell/browser
guides, generated by `scripts/windows/generate-setup-demos.py`. Each is 1280 × 480,
20 frames at 500 ms per frame, looping every 10 seconds. Matching PNGs summarize
all four steps for reduced motion and animation fallback.

The artwork never reads or shows a real account, terminal session or browser.
Installation waits are shortened and labelled. The actual commands remain in
the selectable, copyable setup controls below the illustration. Sign-in checks
remain on the separate Check Setup page.

To regenerate on Windows, run `python scripts/windows/generate-setup-demos.py`
with Pillow available. Segoe UI and Consolas are used from Windows' system font
directory during generation; font files are not distributed. Normal application
builds embed the committed images and do not run the generator.

Generation first checks both providers' command strings against `ProviderSetup.cs`
and fails if they drift. The Codex install illustration also states its Node.js
and npm prerequisite.
