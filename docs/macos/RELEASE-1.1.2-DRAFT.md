# Llumi 1.1.2 — draft release notes

- Adds in-app update support for future macOS releases.
- Prevents internal Claude usage bucket names from appearing in the Usage interface.

Existing Llumi 1.1.1 users need to install 1.1.2 manually once. Future compatible macOS updates can then be installed directly from Llumi.

This is an unpublished candidate. Local signed updater validation passed; Apple notarization, stapling, final Gatekeeper verification and release authorization remain pending.
