# Llumi 1.1.2 — draft release notes

- Adds in-app update support for future macOS releases.
- Prevents internal Claude usage bucket identifiers from appearing in the normal UI.

Existing 1.1.1 users must install 1.1.2 manually once; future compatible updates can then be delivered in-app.

This is an unpublished candidate. Signed updater installation validation and final release authorization remain pending.
