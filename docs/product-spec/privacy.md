# Privacy
Llumi has no account, telemetry, analytics or backend. It does not inspect prompts, responses, conversations, terminal contents, repositories, keystrokes or screen pixels. It never stores or copies provider credentials, tokens, cookies or keys. Provider authentication remains provider-owned; provider subprocesses contact their own services under their own settings and terms.

Usage-only subprocesses run in explicit isolated working directories outside active projects, with Git traversal bounded and inherited repository-routing variables removed. Disable unrelated session persistence and project/tool configuration where the provider interface allows it. No inference messages are sent. Bound lifetimes, output, memory retained from output and cleanup.

Keep readings/account continuity in memory. Persist only application preferences and small sanitized rotating diagnostic events. Raw provider output and identity never enter logs. No provider executable or ambiguous provider SDK is redistributed. Vendor artwork retains its owner's rights and must not imply affiliation or endorsement.

macOS 1.1.2 direct-distribution candidates use Sparkle to request an HTTPS appcast and approved update archives. Update hosts see ordinary HTTP request metadata, including IP address; requests carry no provider credentials, identity, usage readings or bucket identifiers. System-profile submission and silent installation are disabled. This updater traffic is distinct from provider subprocess traffic. Existing website analytics audit findings are not resolved by this integration.

macOS 1.1.3 adds explicit opt-in automatic downloads using the same Sparkle path. It prompts before restarting; Later leaves the process running and the prepared update installs on quit. Local completion metadata contains numeric origin/target versions/builds and host-path hashes only. It is never exported in diagnostics or sent to the website. Release notes open on request at the exact trusted HTTPS version route. No updater HTML, credentials or provider readings enter those windows.
