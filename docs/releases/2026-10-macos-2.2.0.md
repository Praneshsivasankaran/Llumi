# Llumi 2.2.0 for macOS — publication receipt

Published with explicit owner authorization on 12 October 2026. This release
includes background startup, a compact menu-bar usage popup, app-linked appearance,
optional configurable usage alerts and missing-value correctness for Claude quotas.
Claude Code and Codex remain the supported providers; no new provider integration
is advertised or included. No separate Llumi account is required.

## Public destinations

- [Mac release and installer](https://github.com/Praneshsivasankaran/Llumi/releases/tag/llumi-macos-2.2.0)
- [Website download](https://tryllumi.com/#download)
- [Mac 2.2.0 release notes](https://tryllumi.com/releases/macos/2.2.0/)
- [New signed update feed](https://tryllumi.com/appcast-v2.xml)

Existing 1.1.3 and earlier users must quit Llumi and install 2.2.0 manually once,
replacing the app in Applications. The original updater private key was lost;
the old feed remains unchanged and cannot migrate those installations.

After this installation, future compatible releases use the new signing key/feed.
Automatic checks and downloads follow the existing Automatic Updates setting;
the migration does not silently enable it. Update ready offers **Restart and update**
or **Later**; Later keeps the app running and a prepared update can install on
normal Quit. Preserve the new key and feed and the minimum update version **5**
when creating later releases. No future public release was created by this task.
