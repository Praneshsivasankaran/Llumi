# macOS 1.1.3 local preview

Version 1.1.3/build 3 is a local review candidate on 5 October 2026. The owner requested review of the new build, then a private update of the installed 1.1.2 on their Mac, before any public publication. GitHub, the website and the production feed have not been changed by this work.

## Changes

- Light setup and a minimal welcome screen; light appearance migrates once, then later choices are respected.
- Persistent Codex/Claude monitoring switches in setup and Settings. Disabled providers stop usage/activity work and disappear from Usage and the monitor.
- Simplified setup copy with bundled five-second illustrative demos, pause/replay controls and reduced-motion posters.
- Equal provider card height, removed redundant copy, Retry and retained diagnostics.
- Free monitor dragging with a movement threshold, saved display-relative position, screen bounds handling and Reset Position.
- Updates in Settings, automatic signed information checks on foreground open and scheduled checks, an available-update banner, and native Sparkle installation.

Windows behavior and release artifacts are unchanged.

## Validation

The macOS suite passed 109 tests with zero failures. Distribution tooling passed 17 tests, updater policy passed 13 tests, and the production privacy check passed. The universal Release build contains arm64 and x86_64. A subsequent render-only logo correction passed a Release rebuild and native visual inspection.

The local app and DMG use the existing Developer ID publisher/team, Hardened Runtime and secure timestamps. Strict nested code verification passed. Pinned Sparkle tooling generated and verified the private feed and archive signatures. This candidate has not been submitted to Apple for notarization and is not a public release artifact.

Native Release review verified About displays 1.1.3, the light welcome and provider switches, both setup guides/demos, Settings update controls, and a manual update check. Turning Claude monitoring off removed its Usage card; re-enabling it immediately queried usage. Both providers were restored enabled afterward. The manual check reported public 1.1.2 as the newest published version while the preview ran 1.1.3.

Monitor geometry, drag threshold, persistence and screen-change cases passed unit tests. The monitor's hover/expanded rendering was captured in a Debug fixture. Physical drag and display-change acceptance remain for the owner's review.

## Private update boundary

The actual `/Applications/Llumi.app` remains 1.1.2/build 2 with its original executable hash. A recoverable bundle and preference backup, signed 1.1.3 preview, private DMG/feed and reversible update runbook are held outside the repository in the owner's local cache.

No local feed server or installed-host feed override has been started. The private update has not been downloaded, installed or accepted. The unchanged signed 1.1.2 host must still demonstrate actual localhost transport, signed feed/archive acceptance, installation and relaunch. A successful curl or signature-tool check alone does not establish that flow. Restore the previous feed preference after the test. Public publication requires the owner's later explicit approval and the normal notarization/distribution checks.
