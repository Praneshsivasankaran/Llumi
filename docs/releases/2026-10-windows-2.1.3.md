# Llumi 2.1.3 for Windows

A clearer Windows experience: simpler setup, complete allowance details and a steadier compact monitor.

## Getting started

- A clean, centered welcome screen with sharp Llumi artwork, clearer steps and illustrated PowerShell guides for Codex and Claude Code.
- Switch each provider on or off during setup and in Settings. Turning a provider off stops its monitoring and removes its usage card and monitor entry. Both can be off.
- Check Setup separates being signed in from having a usable allowance reading, with Retry available when another check can run.
- Setup always uses Light. Existing appearance preferences move to Light once for this update; any Dark or System choice you make afterward stays saved.

## Usage and allowances

- See all supported general, model and additional time limits, with remaining percentages and reset times when reported. Spark, Opus and Sonnet have simpler labels.
- The compact monitor prioritizes a general five-hour limit, then a general weekly limit, then the shortest other supported general window. Model-specific limits stay in the details.
- Clearer Not reported, Unsupported format, Unsupported billing, Unavailable and Stale states, with zero and exhausted allowances displayed correctly.
- Fixes intermittent Claude readings disappearing when a usage request fails. A previous reading stays visibly Stale only when the same account can be verified; changing accounts or signing out clears it.
- More reliable retries and refreshes around resets, rate limits and sleep, without overlapping provider requests.

## A more polished Windows app

- Equal usage cards, rounded controls, animated switches, consistent provider artwork and quieter Today, Yesterday and date labels.
- A steadier draggable monitor, saved display position and Reset Position. Expanded details keep complete allowance rows, with Open Usage when more limits need room.
- Clearer keyboard focus and accessible allowance/status details. Animations respect Windows motion preferences.
- A simpler Settings and About experience, with release notes on the Llumi website and fewer repeated menu actions.

## Availability

Requires Windows 10 22H2 or later, or Windows 11, on x64. Windows installation and updates continue through [Microsoft Store](https://apps.microsoft.com/detail/9NV153Q5K5MQ).

The owner approved this version for public release on 2026-10-08 after testing the local build. Microsoft Store Submission 5 was submitted on 2026-10-08 and is **in certification**, with preprocessing in progress and automatic publication after certification selected. Version 2.1.3 is not yet verified publicly available; the last verified public Store version remains 2.0.2.0.

Windows retains its native tray, startup controls and desktop monitor. This update does not add the macOS updater or a Windows direct-download package.

Implementation and validation history: [Windows 2.1.3 review](../windows/LOCAL-2.1.3.md) and [product contract](../product-spec/windows-213.md). Detailed local review evidence is kept outside the public repository.
