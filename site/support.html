A little help

Llumi Support

Help with installation, provider compatibility and the little things that get in your way.

Llumi is developed by Pranesh S.

Start with Check Setup

Open Settings in Llumi and use Check Setup. Codex and Claude Code must be installed and signed in separately through their own tools. Llumi does not install providers or accept API keys.

Missing or stale usage

Check that the affected provider is installed, authenticated and working. Refresh in Llumi. An unknown value means Llumi could not verify that allowance; it does not mean your allowance is exhausted. Claude’s compact value uses the 5-hour window.

The compact monitor is hidden

The monitor follows supported coding activity. Check that the monitor is enabled in Llumi’s settings and a supported coding session is active. You can still open the main app to view usage.

Report a problem

Include your operating system, Llumi version, installation source and steps to reproduce. For provider compatibility issues, include the affected Codex or Claude Code version.

Review screenshots and diagnostics before sharing. Do not post credentials, authentication files, tokens, private conversations, source code or full terminal history. Reading issues is public; creating an issue requires a GitHub account.
